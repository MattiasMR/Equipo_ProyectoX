Carpeta de evidencia para el trabajo autónomo entre Clase 1 y Clase 2.

## Proyecto

- Nombre corto: TurnoEstudio
- Problema general: planificación académica rota por turnos variables.

- Completar integrantes reales.
- Registrar el equipo en Canvas, en `Grupos Proyecto`.
- Reemplazar candidatos sugeridos por personas reales.
- Contactar al menos 3 candidatos.
- Realizar 1 entrevista piloto de 15 a 20 minutos.
- Completar el registro post-entrevista con hechos, costos, alternativas actuales y citas textuales.
