# ProyectoX / Ritmo

Proyecto de Innovacion y Emprendimiento Tecnologico orientado a estudiantes de pregrado que trabajan con turnos variables o extensiones de jornada avisadas con poca anticipacion.

## Equipo

- Mattias Morales
- Ariel Van Kilsdonk
- Francisco Polo
- Carlos Orellana

## Problema

Cuando un turno cambia o se extiende con poca anticipacion, el plan academico del estudiante deja de ser ejecutable. Las herramientas actuales registran fechas, pero no ayudan a decidir que mover, que priorizar y que riesgo aceptar.

## Hipotesis critica E2

Si estudiantes del segmento reciben una propuesta de replanificacion despues de una extension de turno, al menos 3 de 5 podran reconstruir un plan semanal viable sin ayuda en 3 minutos o menos.
